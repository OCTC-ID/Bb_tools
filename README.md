# Heading Banner Maker

A one-page tool for OCTC faculty: type a heading, pick a style and a level, and download a PNG banner for the Blackboard Ultra content editor.

**Use the tool:** https://octc-id.github.io/Bb_heading_banner_maker/

## What it makes

Three styles (Collegiate, Varsity, Minimal), each at three heading levels, in OCTC navy and gold.

| Level | 1200 px wide | 2400 px wide (default) | 4800 px wide |
|---|---|---|---|
| 1 | 1200 x 240 | 2400 x 480 | 4800 x 960 |
| 2 | 1200 x 180 | 2400 x 360 | 4800 x 720 |
| 3 | 1200 x 120 | 2400 x 240 | 4800 x 480 |

Level 1 matches Blackboard's 5:1 banner shape. Levels 2 and 3 are shorter strips for sub-headings.

## Accessibility

A banner is an image of text. When you add one in Blackboard, paste the heading into the image's alt text. The tool shows the alt text to copy.

## Files

- `index.html`: the whole tool (page, styles, and the script that draws the banners). Fonts load from Google Fonts; there are no other dependencies.
